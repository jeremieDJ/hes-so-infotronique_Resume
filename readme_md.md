## 🚀 Comment naviguer dans ce dépôt ?

1. **Parcourir les dossiers :** Naviguez dans les dossiers du dossier principal pour trouver la matière recherchée.
2. **Format :** La plupart des fiches sont rédigées en Markdown (`.md`) pour une lecture rapide et un affichage optimal directement dans GitHub.
3. **Recherche :** Utilisez la barre de recherche native de GitHub (`t` sur votre clavier dans le dépôt) pour trouver un sujet précis par mot-clé.
